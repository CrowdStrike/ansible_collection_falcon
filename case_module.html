crowdstrike.falcon.case module – Manage Falcon cases

Note

This module is part of the crowdstrike.falcon collection (version 4.15.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install crowdstrike.falcon. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: crowdstrike.falcon.case.

New in crowdstrike.falcon 4.15.0

Synopsis

  • Create and update Falcon cases.

  • The same task creates the case when it is missing and updates it when it is different.

  • The API cannot delete a case. To end the work on a case, set status=closed.

  • Closing a case does not change the alerts in it. Use the alerts API to close them.

Requirements

The below requirements are needed on the host that executes this module.

  • Cases [READ, WRITE] API scope

  • CrowdStrike FalconPy >= 1.5.5

  • crowdstrike-falconpy >= 1.5.0

  • python >= 3.12

Parameters

Parameter

Comments

alerts

list / elements=string

The composite IDs of the alerts to add to the case as evidence.

The module only adds alerts. It does not remove an alert that is not in this list.

assigned_to_user_uuid

string

The UUID of the user that the case is assigned to.

An empty string removes the assignee.

auth

dictionary

The registered result of the crowdstrike.falcon.auth module, or a dictionary containing the access_token and cloud keys.

If provided, the client_id, client_secret, member_cid, and cloud options are ignored.

Useful when needing to make multiple API calls to avoid rate limiting issues.

access_token

string

The OAuth2 access token to use for authentication.

cloud

string

The CrowdStrike cloud region to use.

This can differ from the module’s cloud argument due to autodiscovery.

client_id

aliases: falcon_client_id

string

The CrowdStrike API client ID to use.

See the Falcon documentation for more information about API clients.

The FALCON_CLIENT_ID environment variable can also be used.

client_secret

aliases: falcon_client_secret

string

The CrowdStrike API secret that corresponds to the client ID.

See the Falcon documentation for more information about API clients.

The FALCON_CLIENT_SECRET environment variable can also be used.

cloud

string

The CrowdStrike cloud region to use.

All clouds are automatically discovered if not specified, except for the us-gov-1 cloud.

The FALCON_CLOUD environment variable can also be used.

Choices:

  • "us-1" ← (default)

  • "us-2"

  • "us-3"

  • "us-gov-1"

  • "us-gov-2"

  • "eu-1"

description

string

The description of the case.

An empty string clears the description.

ext_headers

dictionary

Extended headers that are prepended to the default headers dictionary.

id

string

The ID of the case to update.

The module fails when no case has this ID.

With id, name is the new name of the case.

member_cid

string

The CrowdStrike member CID for MSSP authentication.

See the Falcon documentation for more information about API clients.

The FALCON_MEMBER_CID environment variable can also be used.

name

string

The name of the case.

Required to create a case.

With no id, the module finds the case by this exact, case-sensitive name. It creates the case when no case has this name, and updates it when one case has it. It fails when more than one case has this name; give id in that case.

For a name with a single quote or a backslash, the module searches with the part of the name before that character, then compares the full names. It fails when the name starts with one of these characters; give id in that case.

The name search does not see a new case for about 20 seconds. A later task in the same play that changes this case should use the id from the case return value.

purge_tags

boolean

Remove the tags of the case that are not in tags.

With purge_tags=true and no tags, the module does not change the tags.

Choices:

  • false ← (default)

  • true

severity

integer

The severity of the case, from 1 to 100.

Required to create a case.

status

string

The status of the case.

A new case has the status new when this option is not set.

Choices:

  • "new"

  • "in_progress"

  • "reopened"

  • "closed"

tags

list / elements=string

The tags of the case.

Tags are case sensitive.

The module adds the tags that the case does not have.

With purge_tags=true, the module also removes the tags that are not in this list.

user_agent

string

Custom User-Agent string to use for requests to the API.

The user agent string is prepended to the default user agent string (crowdstrike-ansible/<version>).

See RFC 7231 for more information.

The FALCON_USER_AGENT environment variable can also be used.

Examples

- name: Create a case with an alert as evidence
  crowdstrike.falcon.case:
    name: "Phishing investigation"
    description: "Investigate the phishing alerts of the finance team"
    severity: 50
    tags:
      - phishing
    alerts:
      - "0123456789abcdef0123456789abcdef:ind:fedcba9876543210fedcba9876543210-123456789012345"
  register: new_case

- name: Set the status to in_progress and add tags, by ID
  crowdstrike.falcon.case:
    id: "{{ new_case.case.id }}"
    status: in_progress
    tags:
      - finance

- name: Assign the case to a user
  crowdstrike.falcon.case:
    id: "{{ new_case.case.id }}"
    assigned_to_user_uuid: "9a8b7c6d-5e4f-4a3b-2c1d-0e9f8a7b6c5d"

- name: Remove the assignee of the case
  crowdstrike.falcon.case:
    id: "{{ new_case.case.id }}"
    assigned_to_user_uuid: ""

- name: Close the case
  crowdstrike.falcon.case:
    id: "{{ new_case.case.id }}"
    status: closed
